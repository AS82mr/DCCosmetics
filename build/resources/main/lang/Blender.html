🚀 Minecraft to React Three Fiber Workflow

The definitive guide to exporting, baking, and heavily compressing a Minecraft Spawn City for a Next.js homepage.

Phase 1: Mineways Export

Extract the raw model from the Minecraft world save.

  • Open world in Mineways and select the area.
  • Crucial Settings:
    • Check Simplify mesh (Drastically reduces polygons).
    • Texture Output: Export all textures to three large, mosaic images.
    • Check Fill air bubbles and Seal off entrances.
    • Check Center model around the origin.
  • Export as .obj.

Phase 2: Blender Preparation & UV Unwrapping

  • Open Blender (v5.1+). Delete the default cube, light, and camera.
  • Go to File > Import > Wavefront (.obj) and select your file.
  • Add a Light: Press Shift + A > Light > Sun. Rotate it to cast nice shadows.
  • UV Unwrap:
    • Select the city. Press Tab (Edit Mode).
    • Press A (Select All).
    • Press U > Smart UV Project. Set Island Margin to 0.002 and hit OK.
    • Press Tab to return to Object Mode.

Phase 3: The Pre-Bake Script

Go to the Scripting tab, create a + New script, paste this, and hit Run. This forces blocky textures and prepares the 4K bake target. 

import bpy

# 1. Set all textures to 'Closest' (Pixelated/Minecraft Look)
for mat in bpy.data.materials:
    if mat.node_tree:
        for node in mat.node_tree.nodes:
            if node.type == 'TEX_IMAGE':
                node.interpolation = 'Closest'

# 2. Create the 4K Bake Target Image
image_name = "City_Bake_Final"
if image_name not in bpy.data.images:
    bake_image = bpy.data.images.new(image_name, width=4096, height=4096)
else:
    bake_image = bpy.data.images[image_name]

# 3. Attach Bake Target to all Materials
for mat in bpy.data.materials:
    if mat.node_tree:
        node = mat.node_tree.nodes.get("Bake_Target")
        if not node:
            node = mat.node_tree.nodes.new(type='ShaderNodeTexImage')
            node.name = "Bake_Target"
        node.image = bake_image
        mat.node_tree.nodes.active = node 

print("--- Pre-Bake Setup Complete! ---")

Phase 4: Baking the Lighting

  • Go to Render Properties (Camera Icon).
  • Render Engine: Cycles.
  • Device: GPU Compute.
  • Scroll down to Bake.
  • Bake Type: Combined.
  • Margin Size: 2 px.
  • Click Bake and wait for the progress bar to hit 100%.
CRITICAL: Once done, open the Image Editor window, select City_Bake_Final, and go to Image > Save As. Save it as a `.png` or `.jpg` to your computer. Do not skip this!

Phase 5: The Post-Bake Cleanup Script

Before exporting to GLB, run this second script. It deletes the 198 complex Minecraft materials and replaces them with a single, highly-optimized material using your new baked image. This guarantees a tiny file size. 

import bpy

bake_image = bpy.data.images.get("City_Bake_Final")

if bake_image:
    for mat in bpy.data.materials:
        if mat.node_tree:
            nodes = mat.node_tree.nodes
            links = mat.node_tree.links
            
            # Find the Principled BSDF and Output nodes
            bsdf = nodes.get("Principled BSDF")
            output = nodes.get("Material Output")
            
            if bsdf and output:
                # Delete all other nodes to clean up the file
                for node in nodes:
                    if node != bsdf and node != output:
                        nodes.remove(node)
                
                # Create the final baked texture node
                tex = nodes.new('ShaderNodeTexImage')
                tex.image = bake_image
                tex.interpolation = 'Closest'
                tex.location = (-300, 0)
                
                # Link it to the Base Color
                links.new(tex.outputs['Color'], bsdf.inputs['Base Color'])
                
    print("--- Post-Bake Cleanup Complete! Ready for Export. ---")
else:
    print("ERROR: Could not find 'City_Bake_Final' image.")

Phase 6: Final GLB Export

Go to File > Export > glTF 2.0 (.glb/.gltf).

  • Include: Check Selected Objects (Ensure the city is selected in the viewport!).
  • Mesh: Check Compression (Draco). Set compression level to 6.
  • Materials > Images: Set to WebP Format, Quality 75.

Hit Export. Your file should drop from hundreds of megabytes down to ~10MB!
