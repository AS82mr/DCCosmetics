SQLite / MySQL Schema v2 (DatabaseManager)

SQLite WAL Pre-Migration Backup

Before applying v2 column migrations, SQLite checkpoints WAL (PRAGMA wal_checkpoint(TRUNCATE)) and copies data/database.db into data/backup/database-pre-v2-<ts>.db.

PDC Keys & Threading Architecture

dccosmetics PDC Registry

  • Items & Stats: item_id, item_version, item_uuid, item_category, item_rarity, equipment_slot, instance_stats.
  • Sockets: socket_combat, socket_keystone (legacy slot 1 fallback), socket_keystone_slots (comma-separated multi-socket string), socket_mastery, ks_converted.
  • Pets & Cosmetics: dce_pet_id, dce_pet_level, dce_pet_xp, dce_pet_rarity, cosmetic_id, cosmetic_color, scroll_id, scroll_type.
  • Attributes & Blocks: dce_pet_speed_bonus, dce_bastion_kb, dce_tempo_break, chunk-PDC PlacedBlockTracker array.

Threading & ProtocolLib Rules

  • Main Thread: Bukkit API, inventory mutation, entity/attribute updates, KeystoneMenu click ops.
  • DB Thread (DCEssentials-DB-Worker): Single FIFO executor returning immutable KeystoneSnapshot records; never mutates live KeystoneProfile or ItemStack.
  • ProtocolLib Netty Thread: TooltipPacketListener (listening on SET_SLOT, WINDOW_ITEMS, SET_CURSOR_ITEM, plus SET_PLAYER_INVENTORY if available) reads only lock-free TooltipModeService maps, volatile immutable registry snapshots, and FontImageUtil.GLYPH_CACHE.
