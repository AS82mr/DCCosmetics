DCCosmetics Documentation

The definitive guide to creating zero-lag, NMS packet-based 3D cosmetics.

1. Overview

The DCCosmetics engine is a highly optimized, purely packet-based 3D renderer. It generates geometry via Quaternions by manipulating the background matrix of invisible TextDisplay entities. It bypasses conventional Minecraft physics entirely, resulting in zero server lag and flawless client-side interpolation.

2. The Blockbench Importer

DCCosmetics features a native JSON parser that mathematically converts standard Blockbench elements into universally colored TextDisplay matrices!

Workflow: Creating a Model

  1. Open Blockbench and click File > New > Java Block/Item.
  2. Create your elements (cubes). Do not use textures! DCCosmetics uses physical geometry coloring.
  3. Coloring: You can right-click elements and apply a Hex color, or use the 0-7 palette index.
  4. Centering & Offsets: Go to the Display tab at the top right, select Third Person Right Hand, and adjust your model's position and scale. The DCCosmetics Importer automatically extracts these values to perfectly center your item!
  5. Click File > Save Project As... and save it as a .bbmodel.
Command: /cosmetics import <filename>

Drop your my_model.bbmodel file into the plugins/DCCosmetics/imports/ folder. Run /cosmetics import my_model chest in-game. The engine will instantly convert it to YAML, place it in the correct folder, and hot-reload the plugin!

Debugging Blockbench Geometry

If your faces are "stretching" or leaving gaps, it means your aspect ratio scaling is slightly off. You can fix this globally via command!

  • /cosmetics debugbb corners Shows mathematically perfect flame particles at the 4 corners of the geometry plane.
  • /cosmetics debugbb ratio 0.92 3.5 1.0 Live-tunes the internal matrix stretching algorithm to seamlessly seal models together.

3. The Combat Hit Engine (Swords)

Swords do not float on your back. Instead, they completely override Minecraft's vanilla combat particles (slashes and crit stars) using ProtocolLib, replacing them with explosive 3D Shrapnel Matrix geometry!

The 3-Tier Attack System

In your sword YAML file, map your geometry under the attack_types: section:

id: "my_custom_cosmetic"       # The unique internal ID
type: "sword"
attack_types:
  crit:                 # Triggers on running jumps
    duration: 12            # Ticks it stays alive
    fade: 8                 # Ticks it takes to fade opacity to 0
    burst_1:
      type: "burst"       # Explodes outward aggressively like shrapnel
      sides: 8
      length: 1.2
      width: 0.08
  
  sweep:                # Triggers on standing slashes
    duration: 10
    slash_1:
      type: "flat_ring"   # Progressively draws itself across the Y-Axis!
      sides: 16
      radius: 1.2
      width: 0.15
      
  regular:              # Standard hits (Falls back here if sweep/crit not defined)
    duration: 6
    hit_1:
      type: "solid"
Command: /cosmetics debughit <id> [type] [color]

You can instantly preview your sword animations without hitting an entity! Example: /cosmetics debughit plasma_blade sweep #FF0000 shoots the sweep effect directly in front of your crosshair.

4. The Footstep Engine (Boots)

Boots cosmetics can generate transient holographic footprints, emit custom sounds, and spawn vanilla particles on a perfectly tracked walking cycle!

id: "angel_boots"
type: "boots"
footstep:
  particle: "DUST"
  color: "#FF55FF"
  sound: "BLOCK_AMETHYST_BLOCK_CHIME"
  volume: 0.5
  pitch: 1.2
  • Dynamic Footprints: If your Boots ID contains words like star, heart, or ring, the engine will automatically lay down specialized Unicode holographic footprints behind the player!
  • Toggle Sound: Players can type /cosmetics sound to mute/unmute cosmetic footsteps locally.

5. Kinematics & Wing Engines

DCCosmetics contains native inverse kinematic physics engines. By simply naming your nodes or procedural shapes properly, the engine applies real-time math manipulation to them!

Prefix Trigger Slot Requirement Description
left_ or right_ Boots Injects a procedural walk cycle that accurately measures block distance to swing the leg geometry perfectly matching the player's gait.
wing_left_ or wing_right_ Chest Reads the player state (Falling = gliding, Jumping = fast flap, Sprinting = rhythmic jog) to physically rotate the geometry like real wings.

Global Animations

You can set animated: true globally in the YAML. The animation-type: supports:

  • spin - Rotates the entire cosmetic evenly around the player.
  • float - Smoothly bobs the item up and down on a Sine wave.
  • glitch - Randomly jitters the matrix coordinates.

6. Scrolls & Customise GUI

Cosmetics are physically bound to actual Minecraft weapons and armor! They seamlessly stack with Custom Model Data and enchantments.

Command: /cosmetics scroll <player> <id> [color]

Gives the player a physical Cosmetic Scroll. Players simply drag-and-drop the scroll directly onto an applicable piece of armor/weapon in their inventory to permanently forge the 3D model into it!

Dyeing & Detaching (/customise)

If a player holds an enchanted item with a cosmetic attached and runs /customise, a GUI opens allowing them to detach the scroll (returning it safely to their inventory) or Dye it.

You can control which dyes are available in the YAML:

allowed-colors:
  - "#FF0000:Blood Red"
  - "#00FFFF:Diamond Aqua"

Pro-Tip: If a component's color is left as #FFFFFF (White), the engine will automatically override it with whatever Dye the user selects in the Customise menu!

7. Procedural Shapes Library

If you don't want to use Blockbench, DCCosmetics has a massive mathematical geometry library built right into the YAML parser!

Shape type: Properties Description
cube width, height, depth, hidden-faces True 3D Boxes. You can hide specific walls using hidden-faces: [north, up] to prevent Z-fighting lag when connecting them!
solid length, width, sides, pitch Spawns flat 2D planes. Increasing sides generates multiple planes in an outward circular pattern.
flat_ring radius, width, sides Calculates tangent angles to draw a perfectly sealed flat 2D circle on the floor (or sweeping arc in the air).
cylinder radius, height, sides Same math as a ring, but pitched completely vertically to create 3D walls.
star length, short-length, width, sides Alternates lengths sequentially to draw spiky, aggressive starbursts.
burst length, width, sides Uses a Golden Ratio Fibonacci Sphere algorithm to evenly distribute points across a 3D sphere! Excellent for Critical Hit explosions.
hourglass radius, height, inward-pitch Creates an upper and lower ring that slant inwards toward each other.

8. Commands & Editor Hub

DCCosmetics includes a powerful suite of Admin commands for live-editing and debugging.

Player Commands

  • /cosmetics - Opens the main profile and viewing GUI.
  • /customise - Dye, detach, or mute the cosmetic item currently in your hand.
  • /profile <player> - Inspect another player's equipped cosmetics and gear!
  • /cosmetics sound - Globally mutes all custom footstep sounds for the user.

Admin Core

  • /cosmetics reload - Reloads the configurations. (The plugin also auto-reloads files when you save them!)
  • /cosmetics scroll <player> <id> [color] - Give a physical application scroll.

The Live Sculptor

  • /cosmetics sculpt <id> - Spawns a dummy Mannequin that renders your YAML changes instantly.
  • /cosmetics sculpt editor - Opens an interactive inventory GUI to shift coordinates, add shapes, and change sizes visually!
  • /cosmetics sculpt toggle - Makes the underlying dummy invisible.
  • /cosmetics sculpt clear - Destroys the dummy.

The Debugger Suite

  • /cosmetics debughit <id> [type] - Simulates a sword hit physics effect directly at your crosshair.
  • /cosmetics debugnode <id> - Isolates a single geometry element, turning the rest of the model totally invisible so you can pinpoint issues! Type clear to reset.
  • /cosmetics debugboots - Prints internal Y-Drop tracking vectors to the console.
  • /cosmetics debugbb corners - Plots mathematical flame particles at the corners of Blockbench geometry to verify matrix sealing.
